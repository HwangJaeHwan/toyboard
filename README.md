# toyboard
실제 서비스 환경을 가정하여 성능 최적화와 확장성을 고려해 설계한 게시판 프로젝트입니다.



## 🛠 기술 스택

### Backend
Java · Spring Boot · Spring Data JPA · 
Elasticsearch · MySQL · Jenkins · Redis 

### Frontend
Thymeleaf



# 주요 기능

### 🏠 홈
- 게시판별 최신 게시글 5개 조회 및 메인 페이지에 표시
- 인기 게시글 리스트 제공
- 인기/최신 게시글은 Redis 캐싱을 활용하여 빠르게 응답

### 👤 회원가입 / 로그인
- 아이디, 닉네임 중복 여부 서버 검증
- 이메일 형식, 비밀번호 조건 등 유효성 검사 적용

### 📝 게시글 기능
- 페이징 기반 게시글 목록 조회
- 게시판 유형별(자유, QnA, 공지, 정보) 게시글 조회 및 정렬 지원
- 제목, 닉네임, 내용, 제목+내용으로 검색 가능 (Elasticsearch 연동)
- 추천 수, 조회 수 기준 정렬 지원
- 이미지 포함 게시글 작성 가능
- 추천 기능 → 1인 1회 제한으로 중복 방지

### 💬 댓글 기능
- 댓글 작성, 수정, 삭제 기능 제공
- 댓글 작성자 및 관리자만 수정/삭제 가능
- 댓글에 대해 up/down 기능 적용 (하나만 선택 가능)

### 📄 마이페이지 로그
- 게시글, 댓글, 추천, 신고 등 사용자 활동 기록
- 페이징 처리된 로그 목록 제공
- 각 로그 클릭 시 관련 게시글/댓글로 이동 가능
